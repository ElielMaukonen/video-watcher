Eliel Video Poster

A personal desktop tool for publishing my own videos to my own TikTok account.

Eliel Video Poster is a small command-line tool that runs on my own computer. I log in with my TikTok account, choose a video file and caption, and the tool uploads it with TikTok's official Content Posting API. Before every post I choose the privacy level, the interaction settings and any content disclosures myself.

It is not a public service. It is used only by its author to publish content to the author's own account.
